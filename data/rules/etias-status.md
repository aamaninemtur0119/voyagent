**As of the most recent official-source text this session could directly fetch (dated 28 April 2026), ETIAS is NOT YET operational and NOT currently mandatory.** Exact quote: "The European Travel Information and Authorisation System (ETIAS) is currently not in operation and no applications for travel authorisations are collected at this point." The same page states: "No action is required from travellers at this point." This is consistent with the earlier 29 January 2026 article, which used the same "not yet operational" language.

**Scheduled start date per the 28 April 2026 official article**: "ETIAS is scheduled to start in the last quarter of 2026. The exact start date of ETIAS will be officially communicated later this year."

**Therefore, per the official text located: as of 2026-08-23, Brazilian and Canadian passport holders (both visa-exempt for Schengen short stays) are NOT currently required to hold an ETIAS authorization before travel**, because the system had not launched as of the most recent official article this session could fetch (28 April 2026) and there is no evidence found of it having launched since.
